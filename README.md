# KANOE COSMETICS

Site e-commerce vitrine KANOË COSMETICS, conçu dans l'esprit premium de la référence Makari, avec une identité noire et dorée.

## Fonctionnalités

- Accueil responsive desktop / tablette / mobile
- Navigation e-commerce
- Recherche produit
- Filtres par catégorie
- Panier côté client
- Section produits et collections
- Présentation de la marque
- Menu mobile
- Images KANOË fournies intégrées au projet

## Lancer le site

Le projet est une application statique : ouvrez `index.html` dans un navigateur ou servez le dossier avec un serveur local.

Le dépôt est prêt pour GitHub Pages.
